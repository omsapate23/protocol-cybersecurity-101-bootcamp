HINT 1
An image file can contain information besides the visible pixels.

HINT 2
file identifies the format. strings prints readable text found in file bytes.
You do not need a password, a network connection or a special extraction script.

HINT 3
Try: strings -a poster.png
Then filter that output with grep for the usual flag prefix.
